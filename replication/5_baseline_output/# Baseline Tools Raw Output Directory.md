# Baseline Tools Raw Output Directory

This directory contains the unmodified execution outputs generated by the three baseline security analyzers evaluated in the paper: Gitleaks v8.30.1, Zizmor v1.30.0, and Poutine v1.1.6.

## File Manifest

* `gitleaks_dsa.json`
  * Raw scan output of Gitleaks on the 300 Dataset A workflows (`replication/4_dataset_a_sample/`).
  * Yields 4 alerts on NO_EXFIL workflows (A0039, A0235, A0251, A0259), resulting in an empirical FPR of 1.5% (4/261 on the negative evaluation subset).
  * Manual review confirmed all findings are public-by-design literals (e.g., GPG key fingerprints and pinned commit SHAs).

* `gitleaks_dsb.json`
  * Raw scan output of Gitleaks on Dataset B (`replication/3_dataset_b/workflows/`).
  * Yields 0 detections across all 18 exploit cases (0.0% recall) because credentials are referenced symbolically via `${{ secrets.* }}` rather than hardcoded literals.

* `zizmor_dsa.json`
  * Raw scan output of Zizmor on Dataset A.
  * Contains 2,312 findings across the 300 workflows (alerting on 236 out of 262 evaluable negative workflows, 90.1% FPR).
  * Only 21 of 2,312 findings (0.9%) target secret-handling rules (`github-env`, `overprovisioned-secrets`, `secrets-inherit`), demonstrating that Zizmor evaluates general workflow posture and supply-chain configurations rather than egress data flows.

* `zizmor_dsb.json`
  * Raw scan output of Zizmor on Dataset B.
  * Yields TP=16, FP=11, TN=1, FN=2 (88.9% nominal recall, 91.7% FPR). It flags 11 out of 12 benign workflows, including all four hard negatives (dummy secret names, masked logging, hash-only flows, and fixed HTTP endpoints).

* `poutine_dsa.json`
  * Raw scan output of Poutine on Dataset A.
  * Captures 555 findings across 126 workflows (48.1% FPR on the 262 negative denominator), focusing primarily on build pipeline permissions and action provenance.

* `poutine_dsb.json`
  * Raw scan output of Poutine on Dataset B.
  * Produces 0 findings (0.0% recall) because it lacks an embedded script taint engine to track symbolic secrets into downstream network utilities.

These raw outputs are parsed by `replication/src/12_build_master_results.py` and `replication/src/14_dataset_b.py` to produce Table 4, Table 5, and Figure 3/4.
